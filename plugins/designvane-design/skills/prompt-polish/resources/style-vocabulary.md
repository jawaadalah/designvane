# Style vocabulary — vague word -> observable properties

- premium: matte finishes, thin borders, wide letter-spacing on labels, restrained palette (<=3 colors), generous whitespace
- playful: rounded corners (>=16px), 2-3 saturated accent colors, slight rotations, chunky type
- corporate: neutral greys + 1 brand color, grid-aligned, no shadows, conservative type scale
- editorial: serif display headlines, large type contrast, rules/dividers, asymmetric columns
- brutalist: raw borders, monospace accents, hard shadows (offset, no blur), clashing scale
- cozy: warm palette, soft shadows, rounded type, textured backgrounds, lower contrast
- futuristic: dark surfaces, one neon accent, thin lines, wide tracking, geometric motifs
- minimal: <=2 type sizes per screen, no decoration, whitespace carries the hierarchy
