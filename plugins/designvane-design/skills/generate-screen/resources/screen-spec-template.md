# Screen spec template

## Goal — who, what, success metric
## Layout — skeleton per breakpoint, max-widths, grid
## Hierarchy — dominant element, reading order, primary CTA
## Components — name (kebab-case), content (real copy), variants
## States — default / hover / focus / loading / empty / error / disabled / success
## Tokens — spacing, type, color, radius, elevation actually used
## Content — final copy for every string on the screen
## Build order — implementation sequence + what may be stubbed
## Open questions — anything assumed, flagged for the owner
