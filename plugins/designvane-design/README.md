# Designvane Design

Plan and specify screens before any code exists: generation briefs, prompt polish, tokens, DESIGN.md authoring, critique, and responsive layout rules.

Skills in this plugin:

- `generate-screen`
- `prompt-polish`
- `design-tokens`
- `design-md-author`
- `design-critique`
- `responsive-layout`

Install with the root installer:

```bash
python3 designvane.py install --plugin designvane-design --target claude-code
```
