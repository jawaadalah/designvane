# Designvane Build

Turn a settled design into production UI code: React, Vue, HTML/Tailwind, React Native, dashboards, and form patterns.

Skills in this plugin:

- `react-components`
- `vue-components`
- `html-tailwind`
- `react-native-ui`
- `dashboard-charts`
- `form-patterns`

Install with the root installer:

```bash
python3 designvane.py install --plugin designvane-build --target claude-code
```
