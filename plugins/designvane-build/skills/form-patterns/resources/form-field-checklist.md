# Per-field checklist

- [ ] Business justification written; field deleted if none
- [ ] Label: permanent, visible, programmatically associated (for/id)
- [ ] Hint: format or example where a format exists
- [ ] Input type + autocomplete + inputmode chosen deliberately
- [ ] Required/optional marking consistent with the form's convention
- [ ] Validation timing: blur (format) / submit (whole form)
- [ ] Error message: plain language + exact fix + aria-describedby
- [ ] Longest real value fits (names, addresses, IBANs) without truncation
- [ ] Keyboard-only path complete; focus visible at all times
