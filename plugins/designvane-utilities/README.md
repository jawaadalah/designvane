# Designvane Utilities

Extract, export, and harden designs: DESIGN.md extraction, static HTML export, accessibility audits, dark mode, icon systems, and motion.

Skills in this plugin:

- `design-md-extract`
- `html-export`
- `accessibility-audit`
- `dark-mode`
- `icon-system`
- `motion-design`

Install with the root installer:

```bash
python3 designvane.py install --plugin designvane-utilities --target claude-code
```
