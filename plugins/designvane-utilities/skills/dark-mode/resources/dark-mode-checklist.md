# Dark mode checklist

Tokens
- [ ] Components reference semantic aliases only (precondition)
- [ ] Dark value assigned per alias — none inherited by accident
- [ ] Surface ladder: base < raised < overlay, borders defined

Contrast
- [ ] Body text >= 7:1 preferred in dark (halation margin), min 4.5:1
- [ ] Accent on dark surface measured separately from light

Assets
- [ ] Logo: dark variant or light chip · Photos: slight dim
- [ ] Charts re-mapped; gridlines dimmed; embeds inventoried

Behavior
- [ ] OS preference default; manual override persisted
- [ ] No flash of incorrect theme on load or navigation
- [ ] OLED check: no large pure-black areas adjacent to bright elements
