# WCAG 2.2 AA — quick map for UI work

Perceivable
- 1.1.1 Alt text for meaningful images; decorative = empty alt
- 1.3.1 Structure in markup (headings, lists, table headers), not just visuals
- 1.4.1 No color-only meaning · 1.4.3 Contrast 4.5:1 text / 3:1 large text
- 1.4.10 Reflow at 320px, no 2D scrolling · 1.4.11 UI components 3:1

Operable
- 2.1.1 Everything keyboard-operable · 2.1.2 No keyboard traps
- 2.4.3 Focus order logical · 2.4.7 Focus visible · 2.5.8 Targets >= 24px

Understandable
- 3.2.3 Consistent navigation · 3.3.1 Errors identified in text
- 3.3.2 Labels/instructions present before input

Robust
- 4.1.2 Name/role/value correct for custom widgets
- 4.1.3 Status messages announced (aria-live) without focus theft
